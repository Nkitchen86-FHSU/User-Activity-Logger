# Project Title
 
Assignment - User Activity Logger
 
## Description
 
This program logs the activity of a client. It will log either button clicks or form submissions. Every 2 minutes, a batch summary will be logged in the console and sent to the client's console. Batch data will then be reset for the next batch of logs.

### Dependencies

Please run the following in the bash terminal to install dependencies:
```
npm install
```

### Executing program

Please run the following in the bash terminal:
```
npm run start
```

Then go into a browser and enter to the following link:
http://localhost:3000
